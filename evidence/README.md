# 证据范围

仓库仅纳入课程回归所需的 curriculum、curriculum-v2、curriculum-v3、executor-preflight，以及 web/calibrated-configs.json 引用的六份来源冻结文件。冻结字节与配置不作修改。

历史模型交互、临时执行工作区、大规模调优轨迹、截图和生产接入准备材料保留在原开发机，默认不进入 Git。历史文档指向这些路径时，不代表克隆仓库已取得对应证据，也不代表可以复核全部历史结论。

根目录 skill/SKILL.md 是旧研究冻结和对照构建的依赖，保留用于兼容；日常技能入口始终是根目录 SKILL.md。

正式执行保持 BLOCKED，正式 trials 为 0，外部评审保持 UNVERIFIED。公开源码不改变这些验收状态。
