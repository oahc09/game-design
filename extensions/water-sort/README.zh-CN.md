# 水排序运行时扩展

通过 `extensions/water-sort/index.mjs` 使用包含原六类玩法和 `water_sort` 的扩展注册表。原六类入口继续服务现有 Skill、导出器和登记的 A/B 材料。本扩展接入规格校验、权威状态和标准重放。试玩页提供一个固定关卡。求解器、玩家模型和关卡生成留待后续。

管内颜色按底到顶排列。动作使用 `{type: 'pour', from, to}`，管索引从零开始。目标必须为空或顶部颜色相同，倒液量为连续同色层数和目标剩余容量中的较小值。成功倒液原子更新两根管并使 tick 增加一。拒绝不改变状态，也不产生事件。所有非空管都满且单色时获胜。仍未完成且没有合法倒液时判负。判负检查是此扩展明确加入的终局规则，旧候选对照用于倒液、守恒和胜利。

从仓库根目录运行 `node tools/serve.mjs` 后，访问 `/extensions/water-sort/play.html`。点击试管或用左右键和 Enter 选管。R 或重开按钮恢复初态，Esc 取消选择和倒液提示，F 切换全屏。提示与画面只读取权威运行时状态。

从仓库根目录运行如下命令验证扩展。

```powershell
node --test extensions/water-sort/runtime.test.mjs
```

测试使用原公开夹具，以及此前本地验收的两份 gd-107 候选源码。正式 M7 状态为 `BLOCKED`，trials 为 0。
