# Game Design Skill v0.1 交付审查

## 结论

交付为**可运行、可复验的 v0.1 工具系统**。整份 M0–M7 计划的最终结论仍是 **BLOCKED**，不能称为完成正式效果验证的 v1.0。

已经完成大量真实实现与测试；没有把说明文档、空接口或模拟模型结果写成验收通过。剩余未完成项分为具体集成/配置和外部实验，见下文。

- 六类参考玩法：推箱子、三消、2048、方块拼图、下落方块、街机射击

- 可重现内容生成、预算受控求解、观察受限玩家、多线程批次与断点续跑
- 八维质量向量、真实指标/难度分布、数值搜索/敏感性/Pareto、课程生成/验证
- 性质检查、fuzz、真实运行时缺陷注入、最小反例、60条Golden回归
- CocosAirJS 原生场景/渲染适配、实际浏览器逐步状态/事件/输入对照
- 根目录 SKILL.md、角色/工具路由、未知原型流程、一次真实智能体任务试用
- 108项评测任务、公平暴露模式、冻结器、独立自动评审器、原生输出适配、盲评及统计工具

没有自动安装个人技能、公开发布、调用收费模型或修改原有项目。所有工程操作在独立云端目录完成。

## M3新增的真实数据，不掩盖负结果

- 六类×10seed×3profile：180次长周期试跑，0次外部预算截断。下落方块/射击 competent与strong均10/10胜；2048仍0/10胜，但strong均分11,338.8显著高于random的1,024.4。不能仅凭完成率相同说没有策略差异。
- 56个真实关卡变体、1,120次选型试跑，构造10单元/8阶段课程。标注的是推箱规划与多箱目标追踪，未把需要推动的关卡冒充纯移动教学。
- 200次不重叠留出试跑保留第4/6/8单元共3处难度目标失败。没有用留出集重新调参伪装通过。数值边界的3e-17舍入误差单独修复，真实偏差仍失败。
- 一次真实技能试用另外给出3张可解地图、独立最小推数证明和326次射击调参/留出/策略拆分实验。它保留未达到的目标、源代码变更与回放兼容性复核。

这些数据证明工具实际运行、会暴露问题，不证明用户一定觉得好玩或课程已经校准。详见 `measured-curriculum.md` 和 `evidence/skill/forward-exercise/README.md`。

## 使用与复验

先读根目录README.md。核心只需Node20+；`npm test`及CLI不需要API Key。真实引擎试玩用`npm run serve`。完整工程检查用`node tools/verify.mjs --browser`，浏览器检查需官方Playwright/WebKit。

不要盲目重建Golden或覆盖冻结清单来消除失败。代码、规则、模型、预算、任务或评分规则变更需要新版本；持续保留失败与未知。
