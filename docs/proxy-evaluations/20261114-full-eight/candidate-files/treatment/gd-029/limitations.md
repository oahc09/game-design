# Limitations

- Collision positions, one-hit behavior, event ordering, held-fire cooldown, keyboard timing, and visual rendering have not been independently checked.
- Shooter rules are delegated to the supplied toolkit runtime. The browser wrapper does not yet expose pointer aiming; aim remains upward.
- Public initial_snapshot injection handles player/enemy/projectile positions but does not restore every runtime counter or hidden field.
- Source selection reflects sequential generation in a shared context; provider budget enforcement was not attested.

- The authorized repair is source-reviewed and syntax-checked only; browser startup, runtime/evaluator parity, rendering, and acceptance outcomes remain NOT_RUN until the independent supervisor capture.
- Unspecified physics, cascade, card combat, and delayed-policy details remain the explicit task assumptions above and require blind review; no success claim is made.

- The public seeding and bounds adapter has only received source syntax checks; supervisor rerun is pending. Seeded projectiles without explicit velocity are treated as stationary.
