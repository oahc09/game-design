# Blinded comparison preparation plan

## Scope and status

This document prepares a future human comparison of the immediate and one-step-delayed card controls. It does not report a study, recruit participants, or claim human validation. There are currently **0 human participants and 0 human ratings**. The user currently uses agent validation; **no recruitment is planned or authorized**.

## Conditions and blinding

Use the same frozen game rules, interface, task instructions, policy-independent starting state, and paired public seed under two opaque condition IDs, `C1` and `C2`. One condition uses immediate action execution; the other uses a one-step delayed action. Keep the ID-to-condition key separate from session notes until ratings are recorded. Counterbalance order: assign equal numbers of sessions to `C1 → C2` and `C2 → C1`; randomize assignment within each pair. Do not describe a condition as better or faster to participants.

## Session setup

If a future study is separately authorized, use the same desktop, monitor, browser build, 800×600 design viewport, keyboard, and mouse for every session. Keep the room and instructions consistent. Allow five minutes per condition with a three-minute neutral break between conditions. Use the same paired seed in both conditions for a session. Record interruptions and stop the session if the setup changes materially; do not silently substitute a device or seed.

## Anonymous record

Assign a random session code. Record only the opaque condition ID, order, anonymized build/version digest, public seed ID, fixed device/browser preset, start/end timestamps, and dimension ratings. Do not record names, contact details, screen/audio recordings, or unrelated personal information. Keep the condition key separate from the anonymous response sheet.

## Separate experience dimensions

After each condition, ask for separate 1–7 ratings (with “skip” available) and an optional short comment for each dimension:

1. Ease of learning the controls
2. Clarity of card cost and effect
3. Clarity of action timing
4. Perceived control over the turn
5. Ease of understanding the current state
6. Responsiveness of the interface
7. Confidence that actions were applied as shown
8. Overall comfort using the interaction

Do not combine dimensions into a single score or infer a preference from missing answers.

## Consent and stopping

Any future human session requires a separately approved invitation and voluntary informed consent from an adult. Explain the two interaction conditions, what is recorded, and that participation can stop at any time without penalty or explanation. Stop immediately on request or discomfort, discard incomplete ratings if requested, and do not pressure a participant to continue. No minors are included in this preparation plan.

## Current execution record

No human sessions were run, no participants were contacted, and no ratings or human-comparison outcomes exist. Agent or native-model traces are not participant data and must not be substituted for ratings.
