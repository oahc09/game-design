# 玩法质量校准：稳健训练实验

本轮继续使用当前环境、`gpt-6-luna / high`，只接收有界 JSON 地图和棋盘，不使用 Windows Sandbox，不执行模型生成代码。项目版本保持 0.2.0。

## 改进依据

[上一轮](bot-quality-calibration.zh-CN.md)只有推箱子挑战达到留出目标。旧冻结和失败完整保留；旧留出结果在本轮属于公开的开发诊断，不能再次作为本轮验收样本。

三消的 `random` 策略均匀选择合法匹配交换；`competent` 对应 `objective_greedy`，根据可见棋盘选择立即推进目标的交换，不读取真实补充 RNG。因此，随机完成率高不能直接解释为任意乱点也能通关。本轮比较分数目标与指定颜色收集目标，检验内容与策略区分；这不是对上一轮失败原因的因果实验。

## 实验登记与执行边界

登记文件：[protocol.json](../evidence/bot-quality-calibration-robust-20261011-01/protocol.json)。模型调用之前写入，绑定源码摘要与上一轮 report 摘要、用量、1664次模拟。新实验预算单独登记，不覆盖旧1800上限，也不抹去此前成本。

- 训练：64个新种子 `120001 + i×107`；留出：128个新种子 `180001 + i×109`，与旧训练、旧留出及本轮训练不重合。
- 原完成率、策略差、成功动作数与阶段顺序门槛保持不变；`random`、`competent` 策略及权威运行规则保持不变。
- 一次模型提案，最多8份：推箱子与三消，各2份教学、2份挑战；原始返回、失败、usage保留。
- 推箱子先验证可解与最短动作数，教学步数预算为最短路径加 `[2,4,8,12]`，挑战加 `[0,4,8,12]`，最多16个有效参数候选。
- 三消仍为5×5四色、无初始三连、至少一个合法匹配交换；每份棋盘比较9个分数参数格与9个颜色0收集参数格，最多72个候选。补充权重沿用均匀分布，连锁及计分规则未改。
- 教学分数 `[600,800,1000]`、颜色数 `[6,9,12]`；挑战分数 `[1200,1800,2400]`、颜色数 `[12,18,24]`；各交叉步数 `[8,12,16]`。仅监督方选择这些预先列出的字段，模型不能提交任意扩展字段。
- 最多88个候选，每个128局；两个旧配置baseline共256局，四份冻结配置留出共1024局。理论最多12544局，注册上限12800。QA/回放复核不作为新的策略样本。

入口：`node tools/calibrate-bot-quality.mjs CODEX_EXECUTABLE NEW_DIRECTORY --robust`。`CODEX_EXECUTABLE`为现有可用CLI绝对路径，`NEW_DIRECTORY`必须不存在；输出登记、请求、模型JSONL/usage、候选、逐局ledger、冻结与结果文件。默认入口仍保留旧协议，旧未打开留出实验的修复参数也仍保留原语义。

## 选择和验收

联合选择每个原型的教学/挑战组合：PASS优先，再按注册偏差，达标同分时优先选择完成率带、策略差、阶段完成率差的最小安全裕量更大的组合，最后按ID稳定排序。competent完成率100%与挑战random完成率0%是有利的自然边界，不因贴近这些边界扣安全裕量；成功动作数仍为硬门槛，不参与安全裕量排序。

两原型训练组合必须都PASS才冻结。训练未达标时停止，不冻结、不打开留出。冻结绑定全部候选文件、规格、提案、协议及源码，重新验证后才开启留出。留出结果出来后不换种子、不重选、不调整目标。

统计区间仍是描述性Wilson95区间，门槛基于点估计。增加训练覆盖、选择安全裕量不保证留出达标；未测真人体验、学习曲线、娱乐性，也不是独立盲评或正式M7模型A/B。

## 本轮实际结果

[report.json](../evidence/bot-quality-calibration-robust-20261011-01/report.json)记录 `BLOCKED / NO_VALID_PAIR:sokoban`。本轮实际模型完成1个批量turn，输入27732 tokens、输出6181 tokens，其中reasoning5263已含在输出，不重复计费统计。八份提案、原始事件和用量完整保留。

80个有效候选完成10240局训练，加256局baseline，共10496次参考模拟。另两张推箱子挑战地图经BFS最短解均为6步，低于挑战8步下限，已拒绝；模型自报的“预计8步/10步”没有作为验收证据。

推箱子教学示例：最短4步、预算8步，random7/64=10.9375%，competent64/64=100%，competent成功局平均4步；同一内容另两个预算也达标。这里只是训练结果，不能认证已校准。

三消最小注册偏差的教学候选为颜色0目标9、步数8：random47/64=73.4375%（要求不高于70%），competent54/64=84.375%，策略差10.9375个百分点（要求至少15）。挑战候选为颜色0目标24、步数16：random16/64=25%，competent37/64=57.8125%（要求至少65%），策略差32.8125个百分点达标，成功平均13.486步亦在区间内。这说明本轮挑战训练池已经出现策略区分，但可完成性不足；不能据此认定换目标具有因果改善或泛化效果。

历史1664局与本轮10496局合计12160局，各实验预算分别保留。没有追加第二次模型尝试、扩大本轮预算、修改目标或删除失败。下一项内容修复需要另行登记：挑战图应以可验证的解序列/求解反馈约束结构，三消需要更细的目标与步数覆盖或有意义的局部布局变化；当前没有证据支持仅靠继续提高分数达标。模型用途与原策略约束仍保留，不更换competent策略来制造通过。
