本轮已完成：一次实际模型调用提交六份配置，六类工程检查与预先声明的行为目标均通过；36 局模拟、43 条规范回放复核通过。每类 competent 都为 3/3 WIN。限制仍是有限参考规则、低目标和三种子样本，不是商业玩法或真人教学认证。

## 本轮新增

模型根据六份公开任务和当前参考规则，提交中文设计说明、假设、取舍及 JSON 参数补丁。推箱子由模型设计实际单箱地图；其他五类在明确的参考规则内选择目标、时间/步数和难度参数。监督方将数据物化为完整 GameSpec，再交给注册运行时执行。

这比路由专项增加了实际玩法产物和运行证据，但仍是一次复合模型调用，不是六次独立 trial，也不是新机制代码生成、商业游戏 UI 或真人教学验收。没有把继承的参考规则说成模型独立实现的引擎。

## 固定任务与执行预算

| 原型 | 模型负责的数据 | 固定检查范围 |
|---|---|---|
| 推箱子 | ≤7×7 单箱单目标地图，20–40 步上限 | 实际规格校验、A* 上限 5,000 节点/50 深度/1 秒/2 MiB、WIN 回放见证 |
| 下落方块 | 重力/锁定间隔、1–2 行目标、1,200–2,400 tick 时限 | 保留 10×20 非 Guideline 参考规则，最多 2,400 步模拟 |
| 街机射击 | 敌人 HP、玩家 HP、敌人开火间隔、300–600 tick 时限 | 保留三敌布局，最多 600 步模拟 |
| 三消 | 10–20 moves、150–300 分目标 | 保留 5×5 四色棋盘与已实现规则，最多 80 步模拟 |
| 2048 | 64/128 目标、80–120 步上限 | 保留 4×4 和原生成分布，最多 120 步模拟 |
| 方块拼图 | 2–4 行目标、40–60 次放置上限 | 保留 6×6 原形状/批次，最多 60 步模拟 |

全部使用 seeds 17/29/43 与 random/competent，每份配置六局；对同一实际配置再做 seed17 的 30 步 QA。每局完整规范回放重放，失败和截断不删除。行为门槛为三个 competent 样本至少一次 WIN，仅作为小样本可完成见证，不表示真人难度或总体成功率。

工程验证与行为目标分别记录：spec/replay/QA 通过但没有 observed WIN 时，行为目标仍失败。推箱子必须有实际 WIN 见证；TIMEOUT/资源耗尽不等于不可解，也不换成默认地图让门禁通过。

## 数据边界

接受的是 ≤4 KiB JSON object，仅允许任务声明字段。禁止 shell、路径、版本编辑、未知字段和 prototype/constructor 键，限制嵌套深度、尺寸、数值与对象数量；task/horizon/seed/profile/算法预算均由监督方常量控制。模型的说明文字不作为执行代码或可信测量。

`materializeSpec` 同步动作空间，权威规则保持不变。QA 与 replay 绑定 model patch 后的实际 spec hash，不能拿默认配置 QA 冒充修改后验证。

## 工件与限制

入口：`tools/local-data-design.mjs`；执行器：`src/benchmark/data-design.mjs`。本轮新目录为 `evidence/current-environment-design-20261011-01/`，每份规格、episode、回放、QA、失败和汇总分别保留。原模型路由失败和修正结果不覆盖。

实际模型 usage 为输入 28,208、输出 1,984 tokens，其中 reasoning output 995 已包含于输出。没有额外 native tool 事件，模型运行期间源码不变；请求全文、模型产物与 source_revision 在原 request/report 中保留。

监督复核发现物化规格继承的 evaluation 种子/玩家列表与实际 protocol 不一致，已将声明同步为 seeds17/29/43 及完整解析的 random/competent profiles。原行为数据保留，修正后在 `reverified/` 重新执行，36 局的动作、事件、终态和结果全部一致，43 条回放再次通过；没有重调参数、变更预算/种子或再次调用模型。当前正式交付数据使用这些修正记录，原记录不能作为评价声明一致性的证明。

质量观察：推箱子只有一步，random 与 competent 都全胜；三消和 64 目标的 2048 也都 random 全胜，完成率饱和。这不表示全部策略等价——2048 的 competent 步数更少——也不证明策略深度或学习效果。本轮维持原先小样本可完成目标，不事后新增门槛把通过改成失败，更不把通过升级为娱乐性结论。模型的 `R` 是文字方向缩写，实际 solver/replay 动作为 `RIGHT`。

这六份配置没有留出种子拆分；没有调用次数、帧数或同一配置的回放复核冒充新模型 trial。初次 36 局与元数据修正后的 36 局分别记为原执行和一致性复核，不合并成独立样本 72 局。

文字说明的规则完整性、假设合理性和取舍仍需要真实语义审查；视觉/输入/浏览器、人类理解与学习、公平性和继续意愿本轮未验证。当前路径不具备正式 OS 隔离、provider 硬限额或独立盲评资格，正式 M7 仍不宣称完成。
