## 本轮发现与修复依据

冻结清单的路径使用 `/`，Windows 的 `path.join` 返回 `\`。原 `verifyFreeze` 因此把真实已冻结文件报告为新增。`filesUnder` 现在统一清单键格式；新回归验证保留已知文件、拒绝新文件并检出内容修改。

独立审计测试使用 URL `.pathname` 导致 Windows 驱动器路径错误，已改用 `fileURLToPath`。全量复验另发现目录挂载负例依赖 Linux `/usr`，在本机报 `ENOENT`，已改为实际存在的测试临时目录，仍要求 `RUNTIME_DIRECTORY_MOUNT_FORBIDDEN`。

全局 npm `codex` 缺少 `@openai/codex-win32-x64`；本轮使用桌面应用已有 `codex.exe`（`0.162.0-alpha.2`），没有升级或重装全局 CLI。首次握手脚本因相对 `-C` 路径重复解析而在模型启动前失败；已改为绝对工作目录，第二次成功。两次工件均保留。
