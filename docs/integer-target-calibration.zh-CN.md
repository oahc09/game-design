# 三消挑战整数目标插值

接续[初始选择结构校准](choice-bot-quality-calibration.zh-CN.md)。已确认的推箱子地图和三消教学棋盘保持原内容，三消挑战仅细化整数目标/步数。沿用前序实际`gpt-6-luna / high`输出，本阶段不追加模型调用、不更换模型或玩家策略；历史模型用量保留。当前环境、不使用Windows Sandbox、不执行模型生成代码，包版本0.2.0。

## 登记与固定参数

[protocol.json](../evidence/bot-quality-calibration-interpolation-20261011-01/protocol.json)独占创建，绑定前序protocol/report摘要、四份继承内容、历史累计55936局及校准系列六个实际模型turn的usage。本次注册6000次模拟上限，不扩大或覆盖前序协议。

推箱子教学最短3步/预算5步，挑战最短9步/预算9步；三消教学继承90度旋转棋盘，颜色0目标14/步数10；挑战继承270度旋转棋盘，目标 `[28,29,30]` × 步数 `[17,18]`。两档均匀补充，运行规则、合成人格、完成率带、策略差、成功动作数及阶段顺序门槛不变。

本轮最多9个有效候选，初选2304局、baseline512局、确认1024局、留出2048局，理论总5888，小于6000上限。回放重验不作为新策略样本。

## 选择、确认与留出

初选训练128个新种子 `1400001+i×173`，确认128个 `1560001+i×179`，留出256个 `1720001+i×181`；三个集合内部唯一、互不交叉，不复用前序样本。规格预先声明全部512个种子，没有外部独立种子封存。

原达标优先及偏差排序之后，采用完整安全裕量向量逐项比较，另包含各阶段成功动作数上限距离/20，减少选择贴近15步边界的挑战。此项只影响候选选择，不改验收门槛；前序协议保持原选择规则，历史不重排。

初选固定教学/挑战一对，确认128种子及合并256训练种子都必须达标；确认失败停止，不重选或打开留出。通过后冻结全部初选/确认文件、规格、提案、协议及源码的SHA-256，复核一致性后打开留出。留出之后不调优。

入口：`node tools/calibrate-bot-quality.mjs CODEX_EXECUTABLE NEW_DIRECTORY --interpolate`。CLI路径参数沿用原入口约定，但此模式登记0次新模型调用，不启动CLI；`model-request.json`明确`execution_enabled:false`，report区分模型内容复用与实际新调用。父实验必须完整结束、无pending admissions、未打开留出，推箱子两档和三消教学必须确认PASS。

全量735/735测试通过。结果仅针对固定参考规则和机器人策略，不是真人教学/趣味性认证、独立盲评或正式M7模型A/B。Wilson95区间仍为描述性信息，验收沿用注册点估计门槛。
